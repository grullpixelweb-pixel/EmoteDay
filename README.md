# EmoteDay: Diario Digital con Análisis Emocional

EmoteDay es una aplicación móvil diseñada para ayudarte a rastrear tu bienestar emocional a través de entradas de diario diarias analizadas por IA.

## Características
- 📝 **Escritura rápida**: Interfaz limpia para tus reflexiones diarias.
- 🧠 **IA Emocional**: Análisis automático del sentimiento usando modelos de HuggingFace.
- 📊 **Visualización**: Gráficos de tendencias para ver cómo evoluciona tu ánimo.
- 🔒 **Privacidad**: Almacenamiento local (con soporte para PostgreSQL).

## Estructura del Proyecto
- `/frontend`: Aplicación WebSite
- `/backend`: API Flask (Python) con integración de NLP.

## Cómo empezar

Visit: 

https://emote-day.vercel.app/

Backend: Railway com 30 dias disponible (7 mayo 2026 - 7 Junio 2026)

### Backend
1. Navega a `backend/`.
2. Crea un entorno virtual: `python3 -m venv venv`.
3. Activa el entorno: `source venv/bin/activate`.
4. Instala dependencias: `pip install -r requirements.txt`.
5. Inicia el servidor: `python app.py`.

### Frontend
1. Navega a `frontend/`.
2. Instala dependencias: `npm install`.
3. Inicia Expo: `npm run dev`.
